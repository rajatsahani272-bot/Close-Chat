# CloseChat 💬

**CloseChat** is a friends-only personal messaging application designed for private, simple, and comfortable one-to-one conversations.

## ✨ Current Features

- Modern, responsive messaging interface
- Dark theme with Obsidian, Electric Coral, and Mint accents
- Chat list with user avatars and message previews
- Search through displayed conversations
- One-to-one chat screen
- Message input and send interaction in the current UI demo
- Emoji selection interface
- Friends and friend-request screens
- Accept and decline interactions for demo friend requests
- Delete-message interaction in the demo
- Responsive layout for desktop and mobile screens

## 🛠️ Tech Stack

- React
- Vite
- Material UI (MUI)
- Emotion
- Lucide React
- CSS

## 📁 Project Setup

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository and enter the frontend directory:

```bash
git clone <your-repository-url>
cd frontend
npm install
```

### Run Locally

```bash
npm run dev
```

Vite will provide a local development URL in the terminal.

### Production Build

```bash
npm run build
```

## 🚧 Development Status

CloseChat is currently under frontend development. The current interface uses sample data to demonstrate the main screens and interactions.

The following features are planned for backend integration:

- User registration, login, and logout
- Secure authentication using HTTP-only cookies
- User search by unique username
- Friend requests and friend management
- Real-time messaging using Socket.IO
- Persistent message history using MongoDB
- Message delivery and read status
- Typing indicators
- Disappearing messages
- Delete messages for both participants
- Server-side authorization for chats and messages

**Note:** Planned features are not yet confirmed as fully implemented. Demo interactions should not be treated as production-ready functionality.

## 🎯 Project Goal

To build a private, friends-only messaging application with a clean user experience, real-time communication, and secure access to personal conversations.
